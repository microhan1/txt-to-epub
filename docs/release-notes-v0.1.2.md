## 책갈피 툴 – TXT를 EPUB으로 v0.1.2

「새 버전 확인」을 더한 버전입니다. 변환 결과와 기능은 v0.1.1과 같습니다.

### 새로 더한 것
- **새 버전 확인.** 창이 뜬 뒤 1.5초에 백그라운드에서 도구 이름(`txttoepub`)과 버전, OS 계열(`win`)만 책갈피 서버(chaekgalpi.co.kr)에 보내 새 버전이 있는지 확인합니다. 파일은 보내지 않고, 하루 한 번만 확인하며, 연결이 안 되면 아무것도 표시하지 않습니다. 위쪽 **새 버전 확인** 체크를 끄면 묻지 않습니다(설정 `update_check`).
- **알림 줄.** 새 버전이 있을 때만 창 아래에 한 줄이 나옵니다(모달 창 없음). **업데이트**는 책갈피 툴 페이지를 열고, **다음에**는 그 버전을 다시 알리지 않습니다(더 새 버전이 나오면 다시 알림). 자동으로 내려받거나 바꾸지 않습니다.
- 알림 줄이 나타날 때 창의 최소 높이를 그만큼 올려, 창이 최소 크기여도 3번 칸 아래(줄간격)가 잘리지 않습니다.

### 확인한 것
- 시험 121개 통과(새 버전 확인 시험 38개 추가, `tests/test_update_check.py`: 하루 한 번 · 끄면 0회 · 오프라인이면 날짜 기록 없음 · 실패 조용히 · `updateAvailable`이 true일 때만 알림 · [다음에] 뒤 재알림 없음 · 책갈피 도메인 밖 주소 거부 · 보내는 것은 슬러그·버전·OS뿐 · 요청 스레드가 Tk 객체를 쥐지 않음 · 요청 중 창 닫기 3회 생존).
- 가짜 서버 응답으로 알림 줄을 띄워 캡처(`docs/update_notice.png`). 알림 전후로 위쪽 칸들의 위치·크기가 같고, 창 높이만 알림 줄만큼(47px) 늘었다가 [다음에] 뒤 되돌아옵니다.
- 임시 폴더에서 exe를 실행해 `settings.json`에 `update_check_last`가 기록되는 것을 확인.
