## 책갈피 툴 – TXT를 EPUB으로 v0.1.1

화면 두 곳을 고친 버전입니다. 변환 결과와 기능은 v0.1.0과 같습니다.

### 고친 것
- **미리보기에 ♪ 같은 글자가 줄마다 붙던 문제.** Windows 메모장으로 저장한 TXT(CRLF 줄바꿈)를 열면 미리보기 줄 끝에 음표 모양 글자가 보였습니다. 줄 끝의 CR(0x0D)을 미리보기 칸이 글자로 그린 것이고, 같은 CR이 EPUB 문단 안에도 들어갔습니다. 이제 파일을 읽을 때 CRLF·CR을 LF로 맞춥니다.
- **창을 작게 줄이면 「3. 책 정보·표지·스타일」 아래쪽(줄간격)이 잘리던 문제.** 최소 크기가 1200×740으로 고정되어 있어 세 칸이 요구하는 높이보다 작아질 수 있었습니다. 이제 최소 크기를 화면이 실제로 필요로 하는 크기(현재 1274×764)로 맞추고, 챕터 표와 미리보기의 기본 줄 수를 줄였습니다.

### 확인한 것
- 시험 83개 통과(CRLF·CR·LF 파일 읽기 시험 3개 추가, `tests/test_newlines.py`).
- EUC-KR(CRLF) 샘플을 GUI와 명령줄에서 변환: 미리보기에 ♪ 없음, EPUB 본문에 CR 없음, 표지 자동 생성.
