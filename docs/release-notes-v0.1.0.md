## 책갈피 툴 – TXT를 EPUB으로 v0.1.0

텍스트 파일(.txt) 소설을 리디페이퍼·크레마·킨들에서 읽을 수 있는 EPUB2로 바꿉니다. 설치 없이 `txt-to-epub.exe`를 더블클릭하면 됩니다. 서명되지 않은 파일이라 SmartScreen 경고가 뜨면 "추가 정보 → 실행"을 누르세요.

### 기능
- 인코딩 자동 감지: EUC-KR·CP949·UTF-8(BOM 유무)·UTF-16, 그리고 Shift_JIS·EUC-JP·GB18030·Big5. 감지 결과와 신뢰도를 보여주고, 미리보기에서 글자가 깨지면 그 자리에서 바꿀 수 있습니다.
- 챕터 자동 분할: 제N장·제N화·N.·N화·Chapter N·第N章·第N話·프롤로그/에필로그. 정규식 직접 입력, 잘못 잡힌 항목 체크 해제, 줄 번호로 추가. 앞부분 목차와 본문 속 번호 목록은 챕터로 잡지 않습니다.
- 문단 처리: 빈 줄 기준 / 줄바꿈 기준 / 자동. 앞뒤 공백과 연속 빈 줄 정리, 하드랩 줄 병합(한국어는 띄어쓰기, 일본어·중국어는 붙임).
- 메타데이터(제목·저자·본문 언어·출판사), 표지(없음 / 이미지 파일 / 제목·저자로 단색 표지 자동 생성), 문단 들여쓰기·줄간격. 글꼴은 지정하지 않아 리더기 설정을 따릅니다.
- 여러 TXT를 한 번에 변환(파일당 EPUB 하나). 원본은 수정하지 않고, 결과 이름이 이미 있으면 `(2)`를 붙입니다.
- 화면 언어 4개(한국어·English·中文·日本語), 명령줄 모드(`txt-to-epub.exe novel.txt --title "제목" --author "저자" --lang ko --cover auto`).

### 확인한 것
- epubcheck 5.3: 시험에서 만든 EPUB 전부 오류·경고 0
- EUC-KR 샘플이 설정 없이 글자 깨짐 없이 변환됨, 300챕터 소설의 목차(NCX) 정확
- 10MB TXT 변환 0.4초(소스 실행), 30MB/3000챕터 1.6초, 최대 메모리 130MB
- 단위 시험 80개 (`python -m unittest discover -s tests`)

### 알려진 한계
- Latin-1·cp1251 같은 단일 바이트 코드페이지는 통계 판정에 맡깁니다. 잘못 잡히면 드롭다운에서 직접 지정하세요.
- 두세 줄뿐인 아주 짧은 파일은 판단할 글자가 부족해 신뢰도가 낮게 표시됩니다.
- 리디북스 뷰어·캘리버·Apple Books에서 여는 확인은 아직 하지 않았습니다. 문제가 있으면 이슈로 알려 주세요.
