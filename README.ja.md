# しおりツール – TXTをEPUBに

[한국어](README.md) · [English](README.en.md) · [中文](README.zh-CN.md)

テキストファイル（.txt）の小説を、Ridipaper・Crema・Kindle で読める EPUB に変換します。エンコーディング（EUC-KR・CP949・UTF-8・UTF-16）を自動判定し、章を自動で分割します。話ごとに分かれた複数の TXT を一冊にまとめることもできます。サーバーなし（新しいバージョンの確認だけ例外、オフにできます）、インストールなし、元ファイルは変更しません。

![変換前後](docs/before_after.png)

## ダウンロード

- **実行ファイル**: [Releases](https://github.com/microhan1/txt-to-epub/releases) から `txt-to-epub.exe` を取得してダブルクリック。インストール不要です。署名のないファイルのため SmartScreen の警告が出たら「詳細情報 → 実行」を選んでください。
- **ソースから実行**:

```bash
pip install -r requirements.txt
python main.py
```

## 使い方

1. TXT ファイルをウィンドウにドロップします。エンコーディングが判定され、冒頭がプレビューされます。文字化けしていればその場でエンコーディングを変えます。
2. 検出された章の一覧を確認します。誤検出はチェックを外し、抜けた章は行番号で追加します。
3. タイトル・著者・本文の言語・表紙・スタイルを決めて **変換** を押すと、元ファイルの隣に `<元のファイル名>.epub` ができます。

コマンドラインでも使えます。

```bash
python main.py novel.txt --encoding auto --chapter-pattern "^第.+話" --title "タイトル" --author "著者" --lang ja --cover cover.jpg
```

`python main.py --help` が OS の言語（한국어 · English · 中文 · 日本語）でオプションを表示します。`--lang` は本文の言語（EPUB の `dc:language`）、画面の言語は `--ui-lang` です。

## 複数の TXT を一冊に

話ごとにファイルが分かれたウェブ小説のフォルダを一冊にまとめます。フォルダ（または複数のファイル）をドロップし、ファイル一覧の下で **一冊にまとめる** を選ぶと、1ファイル＝1章の EPUB が一つできます。**ファイルごとにEPUB**（既定）はこれまでどおりです。

- **順序**: ファイル名の数字を数値として読むので、`2話` が `10話` より前に来ます。▲ ▼（または Alt+↑↓）で入れ替えます。
- **章タイトル**: ファイル名から全ファイルに共通する部分（シリーズ名）を除いた残りです（`小説_001話_覚醒.txt` → `001話 覚醒`）。ファイルの1行目がそのタイトルか、`第1話` のような見出しの形なら、その行をタイトルにして本文には二度入れません。2 の一覧でタイトルをダブルクリックすると変更でき、チェックを外すとそのファイルは除外されます。
- **本のタイトル**: フォルダを一つ入れたときはフォルダ名、ファイルを入れたときはファイル名の共通部分が既定値です。結果は最初のファイルのフォルダに `<タイトル>.epub` として保存されます。
- エンコーディングはファイルごとに判定します（EUC-KR の話と UTF-8 の話が混ざっていても構いません）。この方式ではファイル内の章パターンは適用しません（1ファイル＝1章）。

![一冊にまとめる](docs/one_book.png)

*図: 話ファイル 10 個を入れて **一冊にまとめる** を選んだ画面。2 の「章」にファイルが章の順に並びます（韓国語 UI）。*

コマンドラインでは `--merge` です。`--output` を省略すると、最初のファイルのフォルダに `<タイトル>.epub` として保存します。

```bash
python main.py 小説フォルダ --merge --title "タイトル" --author "著者" --output "タイトル.epub"
```

## 章パターンの例

前後の空白を除いた行がパターンで**始まり**、80文字以下であれば、その行を章タイトルとみなします。そのため `第1章 旅立ち` のように番号のあとに副題が続いても拾えますが、本文の文が `プロローグ` や `1. ` で始まると章と誤認されることがあります。その項目は一覧でチェックを外すと前の章の本文につながります。既定のパターンは以下をすべて拾い、正規表現を直接入力することもできます。パターンの一覧は `patterns.json` にあります。

| 言語 | 例 |
|---|---|
| 韓国語 | `제1장 시작`、`12화` |
| 英語 | `Chapter 7`、`CHAPTER XII. The Pool of Tears` |
| 中国語 | `第3章`、`第十二回` |
| 日本語 | `第3話 帰郷`、`プロローグ` |

## 新しいバージョンを確認

起動時に新しいバージョンがあるか確認するため、ツール名（`txttoepub`）とバージョンだけをしおりサーバー（chaekgalpi.co.kr）に送ります。ファイルは送らず、確認は一日一回だけで、設定でオフにできます（上部の **新しいバージョンを確認** チェック）。確認はウィンドウが開いたあとバックグラウンドで行い、接続できないときは何も表示しません。

新しいバージョンがあればウィンドウの下に一行の通知が出ます。**更新** を押すとしおりツールのページが開き、**後で** を押すとそのバージョンは再通知しません（さらに新しいバージョンが出れば再び通知）。自動でダウンロードしたり置き換えたりはしません。

![新しいバージョンの通知行](docs/update_notice.png)

## しないこと

- EPUB3・MOBI・AZW3 は作りません。EPUB2 のみ。
- スペルチェックや文章の修正はしません。
- 画像を含む文書（HTML・DOCX）は対象外です。
- DRM 解除やウェブ小説の収集機能はありません。
- 新しいバージョンを自動でダウンロードしたり置き換えたりしません。
